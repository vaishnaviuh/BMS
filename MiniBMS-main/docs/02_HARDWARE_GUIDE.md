# MiniBMS Hardware Architecture Guide

**Project:** VisionAstraa | KLE Institute of Technology
**Pack:** 3S Li-Ion · 4.3 Ah · 11.1 V Nominal

---

## 1. Battery Pack Configuration

### What is 3S?

**3S** means **3 cells in Series**. Each Li-Ion cell has a nominal voltage of 3.7 V, so:

```
Pack Voltage = 3 × 3.7 V = 11.1 V (nominal)
Pack Voltage = 3 × 4.2 V = 12.6 V (fully charged)
Pack Voltage = 3 × 2.5 V = 7.5 V  (fully discharged — cutoff)
```

The capacity remains the same as a single cell: **4.3 Ah**
Energy stored: `11.1 V × 4.3 Ah = 47.7 Wh`

### Cell Format
**18650 cylindrical cells** — the most common format in EVs, laptops, and power tools.
- Diameter: 18 mm, Length: 65 mm
- Typical chemistry: Lithium Nickel Manganese Cobalt Oxide (NMC) or Lithium Iron Phosphate (LFP)

## 3. Voltage Sensing

**Purpose:** Measure each cell's voltage individually to detect over-voltage and under-voltage conditions.

**How it works:**
- A **resistor voltage divider** brings the high cell voltage down to an ADC-safe level (typically 0–3.3 V)
- The MCU reads the ADC value and converts it back to actual cell voltage using the divider ratio
- For a 3S pack, you need **3 independent voltage measurement channels** — one per cell
- This is critical because cells can drift apart even in a series string

**Thresholds used in MiniBMS:**
| Condition | Threshold |
|---|---|
| Over-Voltage (OV) | > 4.25 V per cell |
| Under-Voltage (UV) | < 2.45 V per cell |

**Real ICs:** BQ76920 (Texas Instruments), BQ76940, LTC6802 (Analog Devices)

## 4. Current Sensing

**Purpose:** Measure the current flowing in and out of the pack.

### Method 1: Shunt Resistor
- A precision low-value resistor (e.g., 5 mΩ) is placed in series with the pack
- Voltage across the shunt = Current × Resistance (Ohm's Law)
- Very accurate, low cost, but generates heat at high currents

### Method 2: Hall Effect Sensor
- Measures the magnetic field generated by current in a conductor
- Non-contact, galvanically isolated
- Used in larger EV packs

**MiniBMS model parameter:** `FAULT_OC = 5.0 A` — fault triggers if |current| > 5 A.

---

## 5. Temperature Sensing

**Purpose:** Monitor cell temperature to prevent thermal runaway.

**Sensor:** **NTC Thermistor** (Negative Temperature Coefficient)
- Resistance decreases as temperature increases
- Typically 10 kΩ at 25°C
- Connected in a voltage divider with the MCU ADC
- Placed physically touching the cells or battery module

**Thresholds used in MiniBMS:**
| Condition | Threshold |
|---|---|
| Over-Temperature (OT) | ≥ 45°C |

**Why 45°C?** Li-Ion cells begin degrading rapidly above 45–50°C. Thermal runaway risk increases significantly above 60°C. Conservative threshold keeps the pack in a safe zone.

## 6. MOSFET Protection Switches (Contactors)

**Purpose:** Electrically disconnect the battery from the load or charger when a fault is detected.

### How it works:
- **Two MOSFETs** are used — one for charge path, one for discharge path
- When BMS is healthy: MOSFETs are ON (gate driven high) → current flows freely
- When BMS detects a fault: MOSFETs are turned OFF (gate = 0 V) → current path broken

### Charge MOSFET
- Blocks current from charger into cells during UV fault or other faults
- Allows charging when in CHARGE state

### Discharge MOSFET
- Blocks current from cells to load during OV, OT, OC faults
- Allows discharge when in DISCHARGE state

**MiniBMS simulation:** `contactor = True` when in CHARGE or DISCHARGE state; `False` in IDLE or FAULT.

**Common discrete MOSFETs:** IRF3205, IRLB3034, AON6512 (for smaller packs)
**Integrated protection ICs:** DW01A + FS8205A (used in 1S/2S packs, e.g., in phone batteries)

## 7. Cell Balancing

**Why is balancing needed?**
Even identical cells drift apart over time due to manufacturing tolerances and uneven aging. In a series string, the weakest cell determines the end-of-charge and end-of-discharge points, wasting capacity in the stronger cells.

### Passive Balancing (used in MiniBMS model)
- Excess energy from the highest cell is bled off as heat through a bleed resistor + transistor switch
- Simple, cheap, but wastes energy as heat
- Works during charging — the full cell is bled while others continue charging

### Active Balancing
- Energy is transferred from a high cell to a low cell using inductors or capacitors
- More efficient, more complex, used in high-end EV packs (e.g., Tesla)

**MiniBMS parameter:** `cell_dv_mv` — tracks imbalance in millivolts. Should stay below 30 mV for a healthy pack.

## 8. Microcontroller / BMS IC

**The brain of the BMS.** Options:

| Option | Use Case |
|---|---|
| **Dedicated BMS IC** (BQ76920, BQ76940) | Production hardware, handles analog front end |
| **STM32 MCU** | Custom firmware, full control, model-based design from MATLAB |
| **Arduino Mega/Due** | Prototyping, education |
| **Raspberry Pi Pico** | Low-cost prototyping with Python |

**MiniBMS academic model:** The MATLAB Simulink model generates the BMS algorithm (state machine, protection, SOC estimation) and the Python/Flask server implements the equivalent logic in software for the backend.

## 9. Communication Interfaces

| Interface | Use in EV |
|---|---|
| **CAN Bus** | Industry standard for EV communication. BMS talks to motor controller, charger, display |
| **UART / RS-232** | Simple serial for debugging and data logging |
| **I2C / SPI** | Communication with sensors (temperature, fuel gauge ICs) |
| **SMBus** | Used in laptop/portable battery packs |

**MiniBMS dashboard:** Shows CAN and UART badges in the topbar to indicate communication bus status.

## 10. Open Circuit Voltage (OCV) Lookup Table

The OCV–SoC relationship is a fundamental property of Li-Ion chemistry:

| SoC (%) | OCV per cell (V) |
|---|---|
| 0 | 2.50 |
| 10 | 3.30 |
| 20 | 3.56 |
| 30 | 3.65 |
| 40 | 3.72 |
| 50 | 3.78 |
| 60 | 3.84 |
| 70 | 3.90 |
| 80 | 3.96 |
| 90 | 4.05 |
| 100 | 4.20 |

The table is used to:
1. **Initialize SOC** on startup (measure OCV at rest → look up SOC)
2. **Validate** Coulomb-counted SOC

## 11. Internal Resistance (IR) vs Temperature Table

| Temperature (°C) | IR (mΩ) |
|---|---|
| 5 | 130 |
| 15 | 110 |
| 25 | 95 |
| 35 | 82 |
| 45 | 75 |
| 55 | 72 |
| 65 | 70 |

**Why does IR matter?**
- The voltage the load sees = OCV − (Current × IR)
- High IR → large voltage drop under load → effective capacity reduced
- Cold cells have high IR → EV range drops in winter
- Aging increases IR → early sign of cell degradation

## 12. Complete Signal Flow Summary

```
Cells → Voltage Divider → MCU ADC → Cell Voltage Reading
                                   → OV / UV Protection

Shunt / Hall Sensor → MCU ADC → Current Reading
                               → OC Protection
                               → Coulomb Counting → SOC

NTC Thermistor → MCU ADC → Temperature Reading
                          → OT Protection
                          → IR Lookup

SOC + OCV Table → SoH Estimation

All Faults → MOSFET Gate Driver → Contactor ON/OFF

MCU → CAN Bus → Motor Controller / Charger / Display
    → UART    → Debug / Data Logger
```

## 13. Safety Design Principles

| Principle | Implementation |
|---|---|
| **Fail-Safe** | Contactors are normally open — power needed to keep them closed |
| **Latching Faults** | Fault state requires explicit reset — prevents auto-recovery into unsafe state |
| **Redundant Sensing** | Both voltage and current monitoring for cross-checking |
| **Conservative Thresholds** | Cutoffs set well before cell damage limits |
| **Cell-Level Monitoring** | Each cell monitored individually, not just pack total |
